# Patrons gratuits – Sahariennes, chapeaux, poches et petites pièces / Free sewing patterns

Site : **https://patrons-gratuits.fr** (anglais : https://patrons-gratuits.fr/en/)

**FR** — Patrons de couture paramétriques gratuits, sur mesure. On saisit ses mesures, le site calcule le patron dans le navigateur et génère un PDF A4 à l'échelle 1:1, à imprimer chez soi. Aucune donnée n'est envoyée : tout se passe sur votre appareil. Les patrons ont été conçus avec [Seamly2D](https://seamly.io/).

- **Sahariennes** : simple ou doublée, avec choix du style (col, fente de dos, manches, épaulettes, poches, pattes).
- **Chapeaux** : bob et bérets (béret basque compris).
- **Poches** : plaquées, à soufflets, à rabat, avec leurs variantes.
- **Petites pièces** : épaulettes, pattes de manche, cartouchière.
- **PDF A4** : plan d'assemblage, récapitulatif des pièces, carré de contrôle de 5 cm, pièces superposées pour économiser du papier (ou séparées, au choix), couleurs lisibles par les daltoniens.
- **PDF d'une page** pour vidéoprojection.
- Guides de couture illustrés pour chaque modèle.

**EN** — Free made-to-measure parametric sewing patterns. Enter your measurements; the site calculates the pattern in your browser and generates an A4 PDF at 1:1 scale to print at home. No data is sent anywhere: everything runs on your device. Patterns were designed with [Seamly2D](https://seamly.io/).

- **Safari jackets**: unlined or lined, with style options (collar, back vent, sleeves, epaulettes, pockets, tabs).
- **Hats**: bucket hat and berets (including the Basque beret).
- **Pockets**: patch pockets, gussets, flaps and variants.
- **Small pieces**: epaulettes, sleeve tabs, cartridge holder.
- **A4 PDF**: assembly layout, piece list, 5 cm check square, stacked pieces to save paper (or separate pieces, your choice), colour-blind-friendly colours.
- **One-page PDF** for projectors.
- Illustrated sewing guides for each model.

## Technique / Technical notes

- Site statique (HTML / CSS / JavaScript), sans dépendance ni serveur / static site, no dependencies, no server.
- Pages françaises à la racine, anglaises dans `/en/` / French pages at the root, English pages in `/en/`.
- Le patron est calculé et le PDF généré dans le navigateur / pattern and PDF are generated in the browser.
