# Patrons gratuits – Poches et autres détails / Free pocket patterns

**FR** — Patrons de couture paramétriques gratuits (poches plaquées, soufflets, rabats…). On saisit ses dimensions, le site calcule le patron dans le navigateur et génère un PDF A4 à l'échelle 1:1. Aucune donnée n'est envoyée. Patrons initialement conçus avec [Seamly2D](https://seamly.net).

**EN** — Free made-to-measure parametric sewing patterns (patch pockets, gussets, flaps…). Enter your dimensions; the site calculates the pattern in your browser and generates an A4 PDF at 1:1 scale. No data is sent anywhere. Patterns originally designed with [Seamly2D](https://seamly.net).
