Glossaire français → anglais

Les termes employés sur ce site pour les poches plaquées et la cartouchière, avec leur équivalent anglais (britannique).

  • Aisance : ease
  • Angles arrondis : rounded corners
  • Angles coupés (chanfrein) : bevelled corners
  • Bande (du béret) : band
  • Bande de soufflet : gusset strip
  • Béret : beret
  • Biseau / biseauté : bevel / bevelled
  • Bob (bucket hat) : bucket hat
  • Bord (du chapeau) : brim
  • Bouton recouvrable : covered button
  • Boutonnière : buttonhole
  • Calotte (côté du chapeau) : sidewall
  • Carré de contrôle : test square
  • Cartouchière : cartridge holder
  • Col : collar
  • Couronne (dessus du chapeau) : crown
  • Cran : notch
  • Découd-vite : seam ripper
  • Dégarnir les angles : trim the corners
  • Devant : front
  • Dos : back
  • Double soufflets : double gusset
  • Doublure : lining
  • Droit fil : grainline
  • Emmanchure : armhole
  • Entrée droite / biseautée : straight opening / slanted opening
  • Envers / endroit : wrong side / right side
  • Épaulette : epaulette
  • Face avant : front piece
  • Languette : tab
  • Ligne de couture : sewing line
  • Manche : sleeve
  • Manche tailleur (en deux parties) : tailored sleeve (two-piece)
  • Manchette : cuff
  • Marge de couture : seam allowance
  • Ouverture pour retourner : turning gap
  • Parementure : facing
  • Patte de boutonnage : button placket
  • Patte de manche : sleeve tab
  • Pente d’épaule : shoulder slope
  • Pétale : petal
  • Pièce d’épaule : shoulder piece
  • Pièce principale : main piece
  • Pince : dart
  • Placer sur le pli du tissu : place on fold
  • Pli du bas : bottom fold
  • Poche (de la cartouchière) : pocket
  • Poche plaquée (ou poche appliquée) : patch pocket (or applied pocket)
  • Rabat : pocket flap
  • Rempli : fold-under allowance
  • Repli : fold line
  • Revers : pocket cuff facing
  • Ruban : ribbon strip
  • Saharienne : safari jacket
  • Soufflet central : centre pleat
  • Soufflet central extérieur : central box pleat
  • Soufflet intérieur central : central inverted pleat
  • Soufflet latéral : side gusset
  • Surfiler (ou surjeter) / surfilage : overlock / overlocking
  • Surpiquer / surpiqûre : topstitch / topstitching
  • Tête de manche : sleeve head
  • Thermocollage : fusing the interfacing
  • Thermocollant : fusible interfacing
  • Tour de taille arrière : back waist circumference
